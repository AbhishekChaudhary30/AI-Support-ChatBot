# Project Brand Assets

This directory contains visual brand assets for the AI Customer Support Chatbot.

## Brand Logo (`logo.png`)

To customize the interface branding:
1. Place your company or project logo file directly into this folder named `logo.png` (path: `assets/logo.png`).
2. **Supported Formats:** PNG (recommended with transparent background), SVG, JPG, or WebP.
3. **Recommended Dimensions:**
   - **Horizontal badge:** 240px × 60px (max height 48px displayed)
   - **Square icon:** 128px × 128px or 256px × 256px
4. **Graceful Fallback:** If `assets/logo.png` is not provided, the application automatically displays an elegant typography-based brand badge: **"SUPPORT AI"**.
